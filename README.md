# Календарь на Vue 3 + Vite

## Стек:

- Vue.js 3 + Composition API
- Vuex (стейт-менеджер)
- SCSS (стили)

Компонент-календарь с возможностью переключения месяцев, а также выбора конкретной даты при клике.

Внизу выводится выбранная дата, при клике по дню она обновляется.

При инициализации компонент может принимать свойство даты в формате "год-месяц-день" и переключать текущий месяц 
и день на нее. Если дата не передана, то берем текущий день.

Реализована возможность переключения языка.
